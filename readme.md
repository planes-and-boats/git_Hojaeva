git init - Включить Git в текущей папке.
git status - Проверить, что происходит (какие файлы зеленые, какие красные, на какой мы ветке).
git add . - Подготовить к сохранению вообще все измененные и новые файлы в папке.
git add <имя\_файла> - Подготовить к сохранению один конкретный файл.
git commit -m "сообщение" - Сделать коммит с текстом описания.

git commit -am "сообщение" - Быстрый коммит (флаг -a + -m). Автоматически делает add и commit для всех уже отслеживаемых файлов. (не видит абсолютно новые файлы)
git branch <имя> - Просто создать новую ветку.
git switch <имя> или git checkout <имя> - Перейти на существующую ветку.

git log --oneline - Посмотреть историю сохранений (коммитов) одной строчкой.

git switch -c <имя> или git checkout -b <имя> - Создать новую ветку и сразу в неё перейти.
git merge <имя\_ветки> - Забрать изменения из указанной ветки в ту, на которой стоишь сейчас.
git branch -d <имя> - Безопасно удалить ветку (если её изменения уже слиты с главной).

git restore <имя\_файла> - Стереть плохой код в файле и вернуть его к состоянию последнего коммита (если еще не делала add).

git restore --staged <имя\_файла> - Убрать файл из индекса (сделать зеленый файл снова красным), но сам код внутри файла не удалять.

git reset --hard HEAD - Жесткий сброс. Стирает вообще все незакоммиченные изменения в папке и возвращает проект к последнему коммиту.

git clone <ссылка> - Скачать чужой/свой репозиторий из интернета в новую папку на ПК.

git remote add origin <ссылка> - Привязать локальную папку к созданному пустому репозиторию в интернете.

git remote -v - Проверить, к какой интернет-ссылке сейчас привязан локальный проект.

git branch -r - Показать список веток, которые лежат на удаленном сервере (в интернете).

git push -u origin main - Отправить изменения на GitHub в первый раз (связывает ветки). В следующие разы достаточно писать просто git push.

git fetch - Проверить, появились ли в интернете новые коммиты (но не скачивать их в файлы).

git pull - Скачать изменения из интернета и сразу объединить их со своими файлами.

git <команда> -h - Краткая, емкая справка прямо в консоли по любой команде. Поможет вспомнить нужный флаг.
